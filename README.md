# tally

Just a li'l tool to help tally. You can enter choices one line at a time:

```
Next: ice cream
Next: apple pie
Next: strawberry rhubarb pie
Next: apple pie
```

or you can pair keys and choices:

```
Next: Luke: ice cream
Next: Aaron: apple pie
Next: Caspian: strawberry rhubarb pie
Next: Jehoshaphat: apple pie
```

... or mix them. (In name mode, lines without names are tallied as "anonymous" votes.)

The results of the tally/vote are then shown to you, and you have the option to save them as a CSV as well.
